Project title: "Using eDNA to Generate Indices of Biotic Integrity in the 
Susquehanna River Basin"

Description: This project includes aquatic macroinvertebrate data collected from 
50 streams throughout the Susquehanna River Basin, which are used to generate indices
of biotic integrity (IBI) scores. IBI scores are used to judge the overall health
of a stream and whether human activity is disrupting it. The data currently in this folder 
is just data that has been supplied by the Susquehanna River Basin Commission. 
Eventually, it will also include data from eDNA sampling and metabarcoding to compare the two methods 
of assessing community assemblage and generating IBI scores.

Folder structure: All data for this project is within the Data folder. This folder 
contains two separate folders, one for raw data and another for processed data. 
All original files are kept in the raw data folder, while any data that has been altered
or reorganized will be in the processed folder. The scripts folder contains all 
R scripts used to manipulate the data and conduct statistical analysis. All figures 
generated by the scripts are within the figures folder.

Acknowledgement: This data was collected and provided by the Susquehanna River Basin
Commission.

Data: There are two main CSV files that will be used throughout this project.
The first file is titled "taxa_data," which contains all of the taxonomic data from the collections
taken by SRBC. Samples were processed by an external lab that morphologically identified all
insects down to genus and other taxa down to the lowest taxonomy possible. Taxonomic information
ranging from phylum to genus are included, each as their own column. The counts for each taxa at each site
are listed in each row, and there is an additional row for the lowest taxonomic level reached.

The second file is titled "site_data," and this file contains all of the information about
each site. This includes site ID, waterbody name, lattitude and longitude,date last sampled, 
and the IBI score calculated using the small freestone stream method.

There is currently excess information in both of these files and the column names need to by modified,
but this will be taken care of during processing.
